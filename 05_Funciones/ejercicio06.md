# Ejercicio 06 — Función `factorial(n)`

Crea una función `factorial` que reciba un número entero `n` y retorne su
factorial (`n! = 1 · 2 · 3 · … · n`). Si `n` es negativo, retorna `None`.
Pide un número al usuario y muestra el resultado.

## Ejemplo
Introduce un número: 5
5! = 120

## Reto

💡 Reto opcional: haz también una versión recursiva:
return 1 if n <= 1 else n * factorial(n - 1).
