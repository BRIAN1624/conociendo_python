# Ejercicio 04 — Función `maximo_de_tres(a, b, c)`

Crea una función `maximo_de_tres` que reciba tres números y retorne el mayor
de ellos. Pide tres números al usuario y muestra el resultado.

## Ejemplo

Primer número: 4
Segundo número: 9
Tercer número: 7
El mayor es 9.



## Pista

Puedes resolverlo con `if/elif/else` o, de forma más corta, con `max(a, b, c)`.
Intenta primero la versión con `if` para practicar la lógica.
