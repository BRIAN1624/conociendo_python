## Sobre la creación de carpetas

No es necesario que crees la carpeta de tu usuario de antemano: git la crea
automáticamente cuando añades archivos dentro.

```bash
# Ejemplo: crear tu carpeta y añadir un archivo
mkdir -p entregas/<tu-usuario>/01_entrada_y_salida/
# ... escribes ejercicio_01.py ...
git add entregas/<tu-usuario>/01_entrada_y_salida/
