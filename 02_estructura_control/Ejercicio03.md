# Ejercicio 03 — Mayor de dos números

Solicita dos números enteros al usuario y realiza un programa que tenga como
salida el mayor de los dos números que tecleó el usuario.

## Ejemplo
```batch
Primer número: 12
Segundo número: 27
El mayor es 27.
```
