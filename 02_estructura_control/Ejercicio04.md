# Ejercicio 04 — Precio de bates (10 o más vs. menos de 10)

Unos bates de béisbol se venden a 100 pesos cada uno. Si se compran 10 o más,
se venden a 100 pesos; si se compran menos de 10, se venden a 108 pesos por
cada uno. Realiza un programa para determinar la salida en cada caso.

## Ejemplos

Ejemplo 1:
```batch
Cantidad de bates: 12
Total a pagar: 1200 pesos
```

Ejemplo 2:
```batch
Cantidad de bates: 4
Total a pagar: 432 pesos
```

## Pista

```python
if (condicion):
    precio = 100
else:
    precio = 108	
```
