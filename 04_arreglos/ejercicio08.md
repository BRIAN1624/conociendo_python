# Ejercicio 08 — Encontrar el menor de 10 valores distintos

Escribe un script en Python donde se solicite al usuario 10 valores, todos
diferentes entre ellos, y muestra en pantalla cuál es el menor de estos.

## Ejemplo
Valores: 15, 3, 27, 9, 42, 8, 11, 30, 5, 19
El menor es: 3


## Pista

Puedes usar `min(arreglo)`. Si lo haces manualmente, inicializa `menor` con el
primer elemento y actualízalo cuando encuentres uno más pequeño.
