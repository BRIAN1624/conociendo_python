# Ejercicio 07 — Encontrar el mayor de 10 valores distintos

Escribe un script en Python donde se solicite al usuario 10 valores, todos
diferentes entre sí, y muestre en pantalla cuál es el mayor de estos.

## Ejemplo

Valores: 15, 3, 27, 9, 42, 8, 11, 30, 5, 19
El mayor es: 42


## Pista

Puedes usar `max(arreglo)`. Si quieres practicar la lógica, recorre el arreglo
comparando con una variable `mayor` que empiece en el primer elemento.
